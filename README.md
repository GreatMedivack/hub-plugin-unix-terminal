# Unix-терминал — темы Agents Hub

Две тёмные темы в духе терминалов 70–80-х годов. Выбор — «Настройки» → «Тема».

**Спокойный фосфор** — зелёная гамма по палитре Everforest:

![Спокойный фосфор](docs/phosphor.gif)

**Спокойный янтарь** — янтарная гамма по палитре Gruvbox:

![Спокойный янтарь](docs/amber.gif)

- Шрифт Terminus на всю страницу — лента, списки, код (`"font_scope": "all"`), крупнее (`"font_scale"`, под размер текста хаба по умолчанию):
  ровно 18px, как в консоли.
- Значки хаба и аватары агентов — пиксельные картинки знаков Terminus: ☺ ↻ ├ /, у агентов `>_` @ # !! *.
  Ещё около 80 частых эмодзи сессий (📦 🔎 🤖 🚀 🐛 …) — тоже знаками Terminus; редкие эмодзи остаются как есть.
- Эти же знаки встроены в шрифт темы — **Hub Term Emoji, основан на Terminus (OFL)**: эмодзи из набора и в «Потоке»,
  и в тексте сообщений рисуются знаками темы.
- Спокойное «ждёт вас» и цвета темы во всём: метки «ждёт вас», «ответ?», «Ждут вас · N» — тонкой пунктирной рамкой
  вместо заливки, у сессии, что ждёт вас, — прямая полоса; участники ленты и значки меню — цветом темы, а не
  оттенком по имени. Стиль (`web/style.css`) включается только при выбранной unix-теме (этого плагина или своей
  с именем «Unix ·…»); с «Системной» и другими темами хаб выглядит как обычно.

Нужен хаб с API плагинов 1.8 (поля шрифта на всю страницу и масштаба —
[PR #28](https://github.com/flagman/agents-hub-core/pull/28), уже в общем хабе). На более старом тема встанет с пометкой «обновите хаб»: цвета и значки будут, а
Terminus — только в заголовках и мельче.

Шрифты Terminus и Hub Term Emoji (производный от Terminus) — SIL OFL 1.1 (`themes/f/terminus-COPYING.txt`). JSON тем и картинки — MIT.
