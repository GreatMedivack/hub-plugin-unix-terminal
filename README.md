# Unix-терминал — темы Agents Hub

Две тёмные темы в духе терминалов 70–80-х годов. Выбор — «Настройки» → «Тема».

- **Спокойный фосфор** — зелёная гамма по палитре Everforest.
- **Спокойный янтарь** — янтарная гамма по палитре Gruvbox.

Шрифт — Terminus на всю страницу (`font_scope: all`), крупнее на треть (`font_scale`) — ровно 18px, как в консоли.
Значки и аватары агентов — текстом тем же шрифтом: ☺ ↻ ├ /, у агентов >_ @ # !! *.

Нужен хаб с API плагинов 1.9. На более старом тема встанет с предупреждением: вместо текста — пиксельные картинки
(они лежат в теме запасом), а до 1.8 Terminus будет только в заголовках.

Шрифт Terminus — SIL OFL 1.1 (`themes/f/terminus-COPYING.txt`). JSON тем и картинки — MIT.
